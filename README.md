## 📋 About This Project
This project implements **object detection**, **instance segmentation**, and **image classification** using **YOLOv8 (Ultralytics)**.  
We trained the model on a custom **waste detection dataset** and evaluated performance across multiple computer vision tasks.

## 🌍 Application
The project focuses on Industrial Defect Detection and Waste Management.  
YOLOv8 enables real-time detection and classification of waste materials such as plastic, paper, and metal.  
This improves automation, reduces manual effort, and increases efficiency in industrial environments.
